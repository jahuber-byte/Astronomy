How to use the model
  1. Tap a holder to cycle through empty → one electron → two electrons → empty. The first electron settles into the front ↑ seat.
  2. Fill lower subshells first: 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s.
  3. Within p or d, put one electron in each orbital before pairing. Each orbital holds at most two, with opposite spins.
  4. Protons identify the element. A = protons + neutrons; charge = protons − electrons.

Equivalent choices of which p or d orbital to fill are accepted. The display uses ↑ for the first electron as a consistent diagram convention.

Guided example and periodic table

Sodium-23 with charge +1 has 11 protons, 12 neutrons, and 10 electrons. Its configuration is 1s² 2s² 2p⁶.

Teacher notes

Version 3 uses specified isotopes and ground-state configurations through 5s. The extended set includes K, Ca, Sc, Ti, V, Mn, Fe, Co, Ni, Zn, Ga, Ge, As, Se, Br, Kr, Rb, and Sr. Chromium, copper, and transition-metal ions are excluded because they require additional configuration rules. The filling ladder is a teaching schematic, not a fixed quantitative energy diagram for every atom or ion. Medals and progress last only for this open tab.
