How do Lewis dot diagrams work?
  • Each dot represents one valence electron.
  • Use the four sides of the element symbol: top, right, bottom, and left.
  • Place one dot on each side before making any pairs. Which side you start with does not matter.
  • For 5–8 valence electrons, begin pairing after four single dots have been placed.
  • Helium is special: its first energy level is full with only two electrons, shown together as one pair.
  • This practice is for neutral atoms only, not ions or bonded molecules.
